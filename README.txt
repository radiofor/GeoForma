GeoForma — Windows 桌面交互标注工作台
===================================

本文对应 GeoForma 1.0.5。
操作说明见 docs/USER_GUIDE.txt，模型配置见 docs/MODELS.txt。

启动与模型
----------
使用 GeoForma Python 环境运行 main.py，或双击 run_geoforma.bat。
命令行：python main.py [project.gfm]。
首次使用可在“设置 → 资源配置”下载或导入推理运行库和需要的模型权重。
支持 SAM 1、SAM 2、SAM 2.1 和 SAM 3 的逐个目标交互标注。
SAM 3 基于 Meta 官方代码，仅调整一处 timm 导入路径以兼容新版接口；权重仅从 1038lab/sam3 镜像下载，
不会回退至官方权重站点。源码环境准备：python environment/prepare_sam3.py。
SAM 3 已验证 Windows NVIDIA GPU 推理及特征缓存恢复，详见 docs/SAM3.txt。
其他模型沿用各自下载源；默认 SAM 2.1 Small，GPU 优先，记住上次选择。
导入或打开影像后加载当前模型；已有影像时切换模型会立即加载。

标注流程
--------
1. 导入 TIF、TIFF 或 VRT，也可拖入文件。VRT 展开为各个 TIF 加入列表，
   不显示整幅拼接影像，不使用自定义 YAML/list 格式。
2. 检查坐标系及模型 RGB 波段；元数据缺失时手动确认。
   自动准备当前影像和下一幅的特征，切换影像后更新准备范围。
   准备时可查看和切换影像；就绪标识按幅更新，保留列表滚动位置。
3. 选择类别，使用工具栏添加正点、负点或框选。正点表示同一个目标内部，
   负点用于排除区域；用模型提示标注另一个独立目标前先保存或取消当前编辑。
   默认开启自动应用、单一多边形和平滑；关闭自动应用后点击“应用”。
   关闭“单一多边形”后，保存时将每个多边形拆成独立标注，在列表中分别显示。
4. 检查轮廓并点击“保存标签”。列表中可通过每行的下拉框修改类别；使用“重塑”
   直接绘制穿越边界的折线，无需预先选中；穿过多个标注时同时重塑。
   右键完成后已保存的标注自动更新并保持“已保存”；未保存的草稿仍需确认。开启平滑后保持平滑显示。
   人工重塑后保留其几何；撤销人工编辑后可恢复模型提示编辑。
5. 未命名项目首次点击“保存”选择保存位置，项目文件使用 .gfm 后缀（内部为 JSON）。
   此后按钮禁用；编辑会自动写回项目文件，无需反复手动保存。
   列表下方第一行为“上一个、下一个”，第二行为“定位、删除”。Del 删除所选标注，Ctrl+Z 可撤回删除；快捷键用于逐步撤销、
   重做和取消；在画布或标签列表按回车可保存标签。工具按钮没有字母快捷键，悬停提示已禁用。
6. 在导出区选择 GPKG、SHP 或 GeoJSON，再点击“导出标签”。
   仅导出当前影像已确认标签；标签字段名默认 class_value，可修改。
   SHP 字段名最多 10 个 UTF-8 字节，默认名称自动写为 class_val；其他过长名称需缩短。
   GPKG/SHP 使用导出区投影设置，GeoJSON 固定 EPSG:4326。
   保存项目或导出标签时只需输入文件名，软件会自动添加所选格式的扩展名。

支持逐个标注目标，并可调整、保存、删除和导出标签。
标注列表显示当前影像的标签及各自状态，未保存的编辑需确认后才能继续。
类别管理支持名称、颜色、标签值，标签值默认从 1 递增。

缓存与恢复
----------
准备缓存是可重建的模型特征，不嵌入项目 JSON。当前缓存归属于一个项目，
切换到新项目时先释放旧模型进程，再清理其影像特征及应用产生的交换文件。
同一数据目录只允许一个 GeoForma 工作窗口；命令行清理、安装和自检也会避让正在使用该目录的窗口。
清理保留模型权重、原始影像、项目、恢复文件和未知文件。
资源后台清理会保留近期可续传文件，并回收超过 30 天未更新的续传残留；
已安装运行库对应的旧下载副本、已损坏下载及明确标记的中断安装临时文件也按期限清理。
同一项目恢复时只清理过期写入临时文件，完整特征保留以便复用，详见“资源配置”。
损坏缓存会重新计算；任务取消不提交迟到结果。下载失败可点击“重试”。
首次保存及后续自动保存均采用临时文件和原子替换。连续编辑合并写入已保存的项目文件；
未命名工作保存在资源目录的恢复区，首次选择项目位置后自动写回该项目文件。
SHP 为多文件集合，失败时尝试事务回滚，不具有断电级整体原子性。

参考与帮助
----------
“导入参考”可添加 NDWI、NDVI、VV 等类型，按同名文件匹配，仅作底图查看。
名称在参考管理表中直接修改，每行末尾符号按钮移除引用。
设置集中管理资源和数据目录；“帮助与诊断”提供操作说明、
任务记录和可复制的依赖版本。详见 docs/USER_GUIDE.txt。

开发验证
--------
python tools/check_dependencies.py
python tools/run_checks.py
测试成功后的自动管理临时目录会清理；失败临时目录至少保留 7 天，之后在下一次测试运行时清理。手动指定 --basetemp 的目录由调用者管理。
旧构建与测试临时目录可先运行 python tools/clean_build_scratch.py 查看计划，加 --apply 后执行；旧验证依赖副本可另加 --obsolete-payloads。正式发行包与审计报告不在清理范围。
新增模块边界：controllers/preparation.py 负责影像准备，controllers/label_list.py
负责列表更新，label_index.py 负责几何展示索引，label_history.py 负责历史回放，
feature_cache.py 负责特征文件预检和缓存路径校验；Qt 界面不执行模型加载和大批量历史回放。
rendering/raster_queue.py 分别合并全图预览和最新视图请求；raster_validity.py 统一平滑及栅格导出的有效像元检查，人工重塑按用户指定的轮廓执行；session_guard.py 保护数据目录会话。
