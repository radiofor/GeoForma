GeoForma 版本与发布约定
======================

首个正式版本为 1.0.0。后续发布采用 主版本.次版本.修订版本。
修复问题递增修订号，兼容的新功能递增次版本号，不兼容变更递增主版本号。
与版本发布对应的对话统一命名为“<版本号>版本”，例如“1.0.0版本”。

版本源：geoforma/distribution.py 的 VERSION。
Windows EXE 属性、应用版本、诊断和安装器从该版本生成；同时更新当前 README 与发行说明。
每次完整构建当前发布包，不把旧 EXE 改写成新版本；清理过期发布材料。
商店包位于 release/<版本号>/store，对应构建日志位于 build/release_<下划线版本号>，
验收报告位于 release/<版本号>/qa。如另行制作普通安装包，安装 EXE、全部同名 .bin、
SHA256SUMS.txt 和 files.json 一起交付。

发布前执行源码回归、冻结版 CPU/GPU 与 CPU 回退、离线路径和中文迁移路径验证；
制作普通安装包时在隔离目录验证安装/卸载及用户数据保留。保留版本化的模型与依赖清单。
发布目录中的验收说明应准确列出实际通过项和仍需实机或商店验证的事项。
