GeoForma 1.0.5 安装与卸载
========================

安装
----
商店版通过 Microsoft Store 安装或更新；提交商店的 MSIX 由商店签名后发布。
普通安装版运行单个安装程序 EXE 完成安装。
默认安装到 C:\Program Files\GeoForma，安装时可选择其他磁盘或目录，安装程序会使用其中的 GeoForma 文件夹；文件夹不存在时自动创建。安装需要管理员授权。更新前请保存项目并退出 GeoForma。
更新普通安装版时，安装程序会检测已有版本，包括安装在其他目录的版本，并先卸载旧版再安装新版。旧版位于自选目录时，Windows 可能要求再次确认卸载权限。更新时保留项目、恢复数据和已配置资源。如旧版或安装路径无法通过安全校验，安装程序会提示如何处理。
独立目录版需保留整个 GeoForma 文件夹，通过 GeoForma.exe 启动。
程序包含 Python、Qt 和 GIS 组件，无需另行安装 Python、Conda 或 QGIS。
GeoForma 使用 Windows 原生推理环境，不要求安装 CUDA Toolkit。

首次配置
--------
推理运行库与模型权重按需配置。
首次打开时可通过“资源配置”自动下载或导入已有运行库及模型权重。
已配置资源可离线使用；不同型号的模型权重分别配置。
GPU 加速需要兼容的 NVIDIA 显卡与驱动，GPU 不可用时使用 CPU。
软件不安装显卡驱动，也不修改系统 Python 或其他程序的运行环境。
详细步骤见“资源配置”。

项目迁移
--------
项目文件保存标签、提示、模型配置及工作状态，原始影像单独存放。
“保存”按钮只用于未命名项目首次选择位置；已有路径后按钮禁用，编辑自动写回正式项目文件。
移动项目时需保留源影像及参考影像，避免文件路径失效。
复制独立目录版时请复制整个程序文件夹，不要只复制 EXE。

数据位置
--------
程序目录：应用、依赖库、离线说明及许可证。
资源目录：运行库、模型权重、特征缓存、日志及未命名工作区的恢复文件。可在资源配置窗口选择存放位置。
更改资源目录时，软件会迁移并校验受管理的运行库、模型、缓存、日志及未命名工作恢复文件；迁移完成后清理原目录中已迁移的受管理文件。已命名项目直接自动保存到项目文件，不随资源目录迁移。少量目录定位及锁信息仍保存在当前用户数据目录，部分设置由 Windows 保存。
项目与原始影像保存在用户选择的位置，影像不会复制到程序目录。

卸载
----
保存项目并退出后，通过 Windows“设置 → 应用 → 安装的应用”卸载。
手动卸载时，可分别选择清理影像缓存和日志、模型权重和 PyTorch 运行库、软件设置、未命名工作的恢复文件；各项默认保留。清理前请留意未保存的工作可能无法恢复。已保存的项目、原始影像和导出成果不会自动删除，无法确认归属的文件也会保留并提示。

版本与许可证
------------
当前版本为 1.0.5。版本信息可在“帮助与诊断 → 操作说明”中查看。
“帮助与诊断 → 依赖库版本”列出运行组件；第三方许可证位于程序目录的 licenses 文件夹。
