VRT 批量导入
============

点击“导入影像”选择已有 VRT，或将 VRT 拖入工作台。
也可直接选择、拖入 TIF / TIFF；支持同时导入多份 VRT 和多个 TIF。

VRT 只用于读取影像文件引用，不作为整幅拼接影像加入列表。
导入后，VRT 中引用的每个 TIF / TIFF 分别加入影像列表，使用各自的文件名、原始尺寸、
投影、网格和波段；逐幅显示、准备、标注及导出，不采用 VRT 的拼接或重投影结果。

同一 TIF 在多个波段中被重复引用时，只加入一次。
同时选择 VRT 和其中的 TIF，或导入项目已有的 TIF，会按完整路径去重。
relativeToVRT="1" 的相对路径以该 VRT 所在目录为基准；绝对路径直接使用。
嵌套 VRT 继续展开为实际 TIF，循环引用和无法读取的引用会报告错误。
文件缺失或 TIF 损坏只跳过对应影像，其余有效影像继续导入。

“导入参考”使用相同规则展开 VRT，然后按每个 TIF 的文件名匹配主影像。
每批填写一种参考类型，例如 NDWI、NDVI、VV；默认名称取 VRT 文件名或文件夹名。

不再支持自定义 YAML/list 清单，不需要填写 format、version 或 images 等字段。
已有项目仍可正常打开；导入来源随项目保存，但之后修改 VRT 不会自动改动已导入影像。
原有项目中的整幅 VRT 记录及其标签保持原样，避免改变已有标注的坐标。

单份 VRT 限制 8 MiB，一次导入的 VRT 总大小限制 64 MiB；
最多导入 100000 个不同 TIF，最多展开 32 层嵌套 VRT。
