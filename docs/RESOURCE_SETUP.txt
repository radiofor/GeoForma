GeoForma 资源配置
================

程序包含界面、GIS 组件和 SAM 适配器；推理运行库与模型权重按需下载或导入。
启动时如缺少运行库或所选模型的权重，将打开“资源配置”。也可在右上角“设置 → 资源配置”手动打开。
未配置时仍可查看项目、手动重塑标签及导出；分割和模型预处理等待资源就绪。
“自动下载并配置”与“手动配置”首次配置即可任选，无需先尝试自动下载。
“手动配置”中可打开官方网站获取文件，也可直接导入已有文件。

资源目录
--------
资源配置窗口的“选择目录”可将运行库、模型权重、影像缓存、日志及未命名工作区的恢复文件放到其他位置。
例如选择 F:\ 后，使用 F:\GeoForma-Resources。新用户默认使用 %LOCALAPPDATA%\GeoForma-Resources；已有资源或缓存的用户默认继续使用旧目录。
更改后旧位置的资源、缓存、日志和未命名恢复文件不会自动移动或删除；切回原目录可继续使用。新位置缺少运行库或权重时需重新配置，缺少影像缓存时需重新准备。
“恢复默认”会切回默认目录，不删除其他位置的资源和缓存。
已命名项目的自动保存文件保存在项目文件旁；项目及原始影像不会被移动。少量目录定位及锁信息仍保存在当前用户数据目录，部分设置由 Windows 保存。

资源状态
--------
运行库和模型列表列出各选项的状态；下方显示当前选项的详情。
已配置：对应运行库验证通过，或对应权重文件已就位。
未配置：尚无此项可用配置；仅下载到缓存中的安装文件不算已配置。
文件不完整：权重文件大小与该型号不符，需要重新获取。
无法访问：文件路径无效或缺少访问权限，检查路径与权限后重试。
待校验：已指定本地权重，尚未确认匹配该型号；在加载模型时校验。
“当前模型”标明项目所选型号。浏览或配置其他型号的权重不会自动切换模型。

1. 推理运行库
选择 CPU 或 NVIDIA GPU 运行库，自动下载或导入界面列出的官方 PyTorch 文件。
运行库安装到所选资源目录，并在独立进程中验证；验证成功后才切换配置。
GPU 加速需要兼容的 NVIDIA 显卡和驱动；GPU 不可用时可使用 CPU。
无需安装 Python 或 CUDA Toolkit；软件不会安装显卡驱动或修改系统 Python。

2. 模型权重
选择需要的 SAM 型号，自动下载或导入官方 .pt/.pth 权重。
所有下载和本地导入均核对固定 SHA256，完成后复制到用户资源目录。
源文件保留。下载另一个型号只配置资源，不会自动切换当前模型。
模型结构在独立推理进程中安全加载和校验。

3. 进度与失败恢复
配置窗口显示正在处理的文件、序号、下载/展开字节数和阶段进度。
下载可取消，完整分块保留供续传；重新下载后仍须完整哈希校验。
配置窗口的“配置记录”保留各阶段结果，完成状态持续显示至下一次操作。
“停止”请求结束当前下载或配置；显示“正在停止”时，等待后台安全退出。
操作进行中，“关闭”、窗口关闭按钮和 Esc 均不会中断配置。
完成、失败或停止结束后可关闭窗口，无需另行保存资源配置。

4. 手动配置
点击“手动配置”，可直接“导入本地文件”，也可先“打开官方网站”查找下载。
请使用清单列出的固定版本，而非主页可能更新的最新版。
“复制下载信息”包含官方网站、文件名、备用下载地址和 SHA256 校验值，供下载工具使用。
备用地址与自动下载可能使用同一来源；无法访问时，可通过官方网站查找对应文件。
SAM：https://github.com/facebookresearch/segment-anything
SAM 2 / SAM 2.1：https://github.com/facebookresearch/sam2
文件下载完成后，点击“手动配置 → 导入本地文件”。
自动下载失败时无需重新获取已完整下载的文件，改用本地导入即可。
完整性校验失败时请重新从清单获取，不能以改文件名绕过校验。
“更多 → 打开资源文件夹”可查看实际使用的资源目录。
“更多 → 清理下载缓存”只移除完整下载的运行库文件，不删除模型、项目或续传文件。
启动后及运行期间约每 24 小时，后台检查应用管理的资源文件，并跳过正在配置的资源：
- 有同名完整资源且通过固定大小与 SHA256 校验时，超过 24 小时的重复续传残留会被移除。
- 没有完整资源的未完成下载，在文件及其可能存在的续传记录均超过 30 天没有更新后移除；期限内可继续续传。
- 损坏并隔离的模型下载、可识别的中断导入临时文件，以及明确标记为未完成的运行库安装目录保留 7 天后清理。
- 已有对应已安装运行库，且文件大小和 SHA256 匹配时，保存超过 30 天的运行库 WHL 下载副本会清理；将来重新配置时可能需要再次下载或导入。
已安装运行库、完整模型权重、原始影像、项目、恢复文件和无法识别的文件不会按这些规则删除。

运行库、模型权重和缓存位于资源目录，不写入应用安装目录。
卸载软件不会自动删除用户影像、项目、恢复文件和自行下载的资源。
