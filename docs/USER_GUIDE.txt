GeoForma 使用说明
================

开始标注
--------
首次使用时可通过“设置 → 资源配置”下载或导入推理运行库及所需的 SAM 模型权重。详细步骤见“资源配置”说明。
导入或打开影像后加载当前模型；已有影像时切换模型会立即加载。没有影像时可先选择模型，导入后再加载。加载期间可查看已有影像，加载完成后显示实际计算设备。
“当前模型”左侧按钮右端的放大镜表示可打开模型选择，右侧显示设备与加载状态，例如“设备：GPU 优先 · 待加载”；首次准备影像时显示“准备中”，模型加载时显示“加载中”，回退 CPU 时会明确标出。
缺少运行资源时提示“资源未配置”，侧栏较窄时简写为“缺资源”。模型任务因进程中断而结束后不再显示已加载设备；有效的影像缓存仍可复用。
1. 点击“导入影像”，选择 TIF、TIFF 或 VRT。VRT 展开成各个 TIF 加入列表，逐幅处理，不显示整幅拼接影像。
2. 检查坐标系和模型波段；RGB 元数据缺失时按提示确认波段。
3. 选择模型与类别。默认 SAM 2.1 Small，GPU 优先；没有可用 GPU 时使用 CPU。
4. 自动准备当前影像及列表中的下一幅；切换影像后更新准备范围，不遍历整个列表。当前影像准备完成后即可添加正点、负点或分割框；下一幅影像预取会为当前标注让出推理任务，完成后继续。
5. 默认自动应用提示；关闭自动应用时点击“应用”。确认轮廓后点击“保存标签”，或在画布和标签列表中按回车保存。
6. 未命名项目首次选择保存位置，之后自动保存；右侧“导出”可将当前影像的已确认标签导出为 GPKG、SHP 或 GeoJSON。
标签字段名默认 class_value，可自行修改。SHP 字段名最多 10 个 UTF-8 字节，默认名称自动写为 class_val；其他过长名称需缩短，或选择 GPKG/GeoJSON 保留完整名称。

提示与重塑
----------
正点表示目标内部，负点用于排除区域；框选用于限制分割范围。
重新框选会替换原框并移除新框外的提示点；可用 Ctrl+Z 逐步撤销到框选之前，或用 Esc 取消当前编辑。
点击工具栏“绘制”可直接添加多边形，不需要模型或影像准备完成。左键逐点绘制，右键或双击完成；Backspace 或 Ctrl+Z 撤回顶点，Esc 取消；中键可平移。完成后选择类别并保存标签。
“单一多边形”只保留一个连通轮廓。关闭时保留全部部件，保存时每个多边形分别成为独立标注，在列表中各占一条；多边形内的孔洞仍保留在所属标注中。一次保存拆出的标注可整体撤销、重做，也可单独选中、编辑或删除。
“平滑”作用于当前模式全部标签，保存和导出沿用该状态。
生成或绘制出轮廓后，右侧列表立即显示对应条目及“未保存”状态；多个部件分别显示。点击列表可对应高亮画布轮廓，类别和轮廓修改同步更新；按回车保存后，同一条目改为“已保存”。取消编辑会移除新建草稿条目，或恢复已有标签的已保存状态。
“重塑”无需预先选中目标，直接绘制折线，自动识别穿过的标注；每个目标需穿过同一外边界至少两次。穿过多个标注时同时重塑，右键或点击“完成重塑”执行。
完成后结果暂存为草稿，按回车或点击“保存标签”统一保存，状态变为“已保存”；批量修改可作为一组撤销、重做。表格选中仅用于图表对应，不决定重塑目标。开启平滑后，重塑过程中及保存后均显示平滑轮廓。
重塑允许人工将轮廓调整到透明缺失区域，也不受原模型框选范围约束；影像边界和其他已保存标签的占用范围仍受保护。原框选记录保留作模型提示来源。
执行成功后编辑线消失，结果仍未确认；点击“保存标签”才保存当前标签。
Backspace 撤回重塑点，Esc 取消未完成编辑。保存不会自动改变所选工具。

模型和标签
------------
SAM 3 使用 Meta 官方代码，权重从 1038lab/sam3 镜像下载，详见 SAM3.txt。
标注列表显示当前影像的已确认标签及未保存草稿。

主影像和参考
------------
“导入参考”可添加 NDWI、NDVI、VV 等类型，按原始文件名与主影像匹配。
参考只用于查看，不参与模型计算；允许部分影像没有参考，不匹配的输入会跳过。
工具栏右侧切换主影像和参考，标签和提示始终保持在上层。
主影像和参考影像中有明确标记的缺失区域透明显示。SAM 输入会用 0 填充缺失像元，预测结果不包含缺失区域；缺失区域附近的轮廓仍可能受填充值影响，请检查后保存。提示和框选不会仅因为落在缺失区而被拒绝，人工重塑可以进入缺失区域。
左侧影像区的“参考管理”与“导入参考”并列，名称直接在表格中编辑，行末图标可移除参考关联，不删除原文件；没有参考时不可用。
最右侧“设置”齿轮提供“资源配置”和“数据目录”；在资源配置中管理推理运行库和模型权重。
左下角“帮助与诊断”集中提供“操作说明”“任务记录”和“依赖库版本”。资源配置窗口可选择运行库、模型、缓存、日志及未命名工作恢复文件的存放位置；已命名项目直接自动保存到项目文件。

保存与恢复
----------
“保存标签”确认单个结果；未命名项目首次点击“保存”选择位置，项目文件使用 .gfm 后缀，内部采用 JSON 格式。之后按钮禁用，工作状态自动写回正式项目文件。
未命名且已加载数据的项目保留恢复记录。已命名项目自动更新项目文件。
上次的已保存项目文件不存在时，“恢复”按钮不可用；请从新位置打开项目。未命名项目没有加载影像或参考数据时不会生成恢复记录，空记录不会启用“恢复”。
项目名称旁的文件夹按钮可打开已保存项目所在目录。打开项目时若影像或参考影像缺失，可选择新位置、从项目移除或取消打开。新影像须匹配原数据的尺寸、波段、数据类型、坐标系和地理变换；请确认选择的是原始数据，程序无法仅凭这些属性验证像素内容是否相同。移除主影像会移除其标注并清除项目撤销和重做记录，不删除磁盘上的数据。项目文件在打开期间被移动时，自动保存会暂停；将文件移回原位置后可继续保存。
参考影像按文件名匹配主影像；重新定位参考影像，或重新定位已关联参考影像的主影像时，请保留原文件名。
影像信息区显示当前文件所在目录，长路径自动换行，可选中复制。切换影像会停止不再需要的预准备，已完成的缓存仍可复用；列表最后一幅只准备自身。
准备特征缓存独立保存在资源目录，不嵌入项目文件；项目只保留缓存关联标识。同一项目可继续复用，新建或切换项目时后台清理当前资源目录中上个项目的影像缓存和临时交换文件，同时释放显示缓存。原始影像、模型权重、已保存标签和恢复记录保留。切换资源目录时，受管理资源会经校验后迁移。
再次激活同一项目缓存时，已中断且超过 7 天的特征写入临时文件会清理；完整特征不会仅因时间过期而删除，以便恢复已就绪影像。完整缓存会随当前项目的影像规模增长，切换项目时统一清理。
同一个数据目录只允许一个 GeoForma 工作窗口运行，避免不同窗口互相清理缓存；再次启动时请切换到已有窗口。命令行清理、安装和自检需要先关闭使用同一数据目录的工作窗口；状态查询仍可使用。
恢复项目时，完整且与影像、模型及当前缓存归属匹配的特征可以复用；有缺失、损坏或配置变化的影像会重新准备。旧单波段影像如果新识别到明确声明的缺失值，需要重新准备一次，已保存标签保留。
SHP 导出包含多个同名文件；如果主 .shp 不存在但同名附属文件已存在，请使用其他导出名称，避免覆盖原文件。

常用快捷键
----------
Ctrl+Z 撤回，Ctrl+Shift+Z 重做，Ctrl+Alt+Z 撤回标签操作。
列表中的类别列为下拉框，可逐条修改。已有标签的类别修改立即生效并支持撤销；未保存轮廓的类别随回车确认保存。列表下方第一行为“上一个、下一个”，仅切换对应高亮并定位，不会丢弃草稿；第二行为“定位、删除”。按 Del 可删除当前选择，Ctrl+Z 或工具栏“撤销”可恢复，Ctrl+Shift+Z 可重做。
Esc 取消编辑，Backspace 撤回重塑编辑点。
其余功能使用按钮操作，不绑定快捷键；滚轮缩放，中键临时平移。

其他栏目提供标注模式、参考、清单、恢复及安装的详细说明，均可离线查看。
